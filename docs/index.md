# fraud-ring-detection

A seeded simulator, reference detector and evaluation harness for coordinated fraud rings. The code
and the full README are on [GitHub](https://github.com/stephen-corgiat/fraud-ring-detection).

- [Explainer lessons](explainer/): the detector in seven short, plain-language lessons, each with a quiz.
- [Walkthrough](walkthrough.html): an illustrated case, from triage to a recovered ring.
- [Methodology](research/method.html): how to measure a detector honestly without real labels.
- [Literature review](research/literature-review.html): what each source claims, and what this project
  took from it.
- [Lessons](research/lessons.html): working rules for detectors against adaptive adversaries.
